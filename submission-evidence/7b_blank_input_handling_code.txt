TASK 7B — Blank Input Handling (server.py)
==========================================
Relevant code from server.py:

    text_to_analyse = request.args.get('textToAnalyze')

    # Handle blank / whitespace-only input
    if not text_to_analyse or not text_to_analyse.strip():
        return "Invalid text! Please try again!"

    result = emotion_detector(text_to_analyse)

    # Handle service-level errors (400 from Watson NLP)
    if result['dominant_emotion'] is None:
        return "Invalid text! Please try again!"

Two-layer guard:
1. Flask route checks for blank/whitespace before calling Watson.
2. If Watson returns HTTP 400 (dominant_emotion=None), Flask also returns the error message.
Both cases return: "Invalid text! Please try again!"
